# Pokémon Card Collection

Live site: [GitHub Pages](https://markyf81-wq.github.io/pitch-black-collector/) or [Vercel](https://pokemon-card-collection-eight.vercel.app/). Both use the same password-scoped cloud collections, while each browser keeps its own offline copy.

A standalone static checklist for the 122 numbered English Pokémon TCG Mega Evolution—Chaos Rising cards and 120 Mega Evolution—Pitch Black cards. It tracks 406 finishes, including the four stamped Chaos Rising variants currently listed by TCGdex. Filter by series, rarity, name, and collection status. The dashboard estimates the value of owned finishes in the selected series, or across both series when **All series** is selected.

Each nonempty collection password opens a separate private collection in Vercel Blob. Press **Sync** to enter a password. On first connection, the checkmarks already on that page are uploaded. The password is saved in that site's local storage, so the page reconnects after reloads without prompting again. Checkmarks save locally immediately, autosync after edits, and refresh from Vercel every 15 seconds while the page is visible, as well as on focus and reconnect. **Sync now** triggers an immediate refresh. Offline edits remain on the device until the connection returns.

**Use another password** opens a different collection. An existing password loads its collection; a new password creates a separate copy of the cards currently shown. The old collection remains in Vercel and on devices that still use its password. The server uses a secret keyed hash of the password to locate the collection; Blob never stores the password itself. Anyone with access to the password or this browser's local storage can open that collection. There is no password recovery. A mistyped password creates a separate collection, so check the cards shown after switching.

The original browser-only Pitch Black storage key is retained. The first password used on an existing browser imports those marks. **Export checklist** creates a backup covering both series; **Import checklist** accepts both the new format and old Pitch Black exports. Importing an old Pitch Black export replaces only the Pitch Black checkmarks. Changes made on separate devices merge by finish and change time when those devices connect again. GitHub Pages and Vercel have separate browser storage, so each URL must be connected once on a device.

The checked-in `cards.json` snapshot was generated from [TCGdex](https://tcgdex.dev/) on 25 October 2026 (Australia/Melbourne). It contains indicative Cardmarket average prices in EUR, updated 24 October 2026, and a [Frankfurter](https://frankfurter.dev/) EUR/AUD exchange rate dated 25 October 2026. Cardmarket often reports one product price for several finishes; normal, holo, and reverse estimates can therefore overlap. These are approximate values, not Australian market sale prices. The page shows the price and exchange-rate dates. Live prices refresh after the snapshot is more than 24 hours old or when **Refresh prices** is pressed. If live sources fail, saved estimates remain visible. Card images load from TCGdex and require an internet connection.

To update the fallback snapshot locally, run `python3 update-data.py`. The frontend is static and is published on GitHub Pages and Vercel. The `api/collection.js` function runs on Vercel. A **private** Blob store is connected to the Vercel project using Vercel's rotating OIDC credentials; no static Blob token is needed. `COLLECTION_PEPPER` is a secret project environment variable. Keep it fixed: changing it makes existing passwords locate different collections. The function permits cross-origin calls from the published GitHub Pages origin and returns `no-store` responses. Local development without those environment variables still supports device-only checkmarks.
